# Roadmap

| Phase | User outcome | Exit evidence |
| --- | --- | --- |
| 0 Foundation | secure, mobile demo shell exists | gates green; RLS and provider tests |
| 1 Brand + Content | Today-to-calendar flow works | 10-step mobile acceptance; safety blocks |
| 2 Video Studio | raw clips become editable finished Reel | sample fixtures render; QC/retry/version tests |
| 3 Instagram | approved content publishes and recovers | sandbox account E2E; capability/permission evidence |
| 4 Growth Intelligence | results produce honest next tests | snapshot backfill, confidence/sample tests |
| 5 Community + Leads | inbound questions become reviewed replies/content | webhook-to-human-approval E2E |
| 6 Polish | reliable daily PWA | accessibility/performance/security audit |

No phase advances with failing lint, types, tests, build, security sanity, or mobile acceptance. External account setup, paid services, public deployment, production posting, destructive migrations, and billing changes require user approval.
